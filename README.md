## Project Description
This program is a Vehicle Rental Management System built in Python that allows a rental company to manage its vehicles, customers, and active rentals through a simple menu-driven interface. Users can add and search for vehicles, register customers, rent out available vehicles while automatically calculating rental cost, and return vehicles once they are no longer needed. All data is saved to files and reloaded automatically, so information is never lost when the application is closed and reopened.
